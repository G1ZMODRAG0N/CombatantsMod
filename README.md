# CombatantsMod (Pre-Release)

An Elden Ring PvP focused mod.

## Description (updated description will come on v1.0)

ERC IS NOT fully released. Yes, this is basically a beta of the mod and  I cannot stress this enough. Combatants in its current form is a pre-release build to allow players to participate in gameplay whilst we build the mod. Once a set number of features and stability is reached only then will ERC be released as v1.0. Once released ERC will be uploaded to Nexus, open source all code, and become much more public facing. Until then be aware that this is a WORK IN PROGRESS

You will see many quality of life features and content not available in vanilla game. As of now this mod is in Pre-Release state. Meaning this version is in no means a representation of the finalized version. Source-code, crediting, features, and various different other content will be available for the v1.0 version on release. 

### Dependencies/Requirements

Recommended to have the same minimum requirements as vanilla Elden Ring:  
    ```- Windows 10 or higher. (Linux support coming)```  
    ```- (INTEL CORE I5-8400 or AMD RYZEN 3 3300X) or better  ```  
    ```- 12 GB RAM  ```  
    ``` - (NVIDIA GEFORCE GTX 1060 3 GB or AMD RADEON RX 580 4 GB) or better  ```  
    ```- Dx12  ```  
    ```- 300-400 MB available space for the base mod +4.8 GB for transmog armor assets```    
ERC does its best to improve performance in-game but we still recommend these minimum specs  
### (You must own the base Elden Ring game and all DLC content)

### Installation/Run

Download the mod from the direct link or GitHub  
    - Windows: https://gizmodragon.com/CombatantsLauncher.zip  
    - Linux (No Transmog): https://gizmodragon.com/combatants-linux.tar.gz  
    - Linux (WithTransmog): https://gizmodragon.com/combatants-no-tm-linux.tar.gz  
    - GitHub: https://github.com/G1ZMODRAG0N/CombatantsMod/releases  
- Open the ```CombatantsLauncher.zip``` and extract ALL the contents to a folder of your choosing. For example you can make a folder on your desktop named CombatantsMod and put the contents in there.
- To start the mod you simply open the ```CombatantsLauncher.exe``` application. 
- From here you may choose your save file at the top left corner of the launcher. Only a few save files types are available at this time. More will be added in the future.
- Once your save file is selected click "Launch Combatants Mod"

### Features

There are a number of features in Combatants. Below is an ever changing list of features:
- Improved P2P connection through [Waygate ](https://github.com/vswarte/waygate-server) that utilizes Steam's Datagram Relay (SDR) to significantly improve latency for Elden Ring.
- Multiplayer client count increased to 1 host + 5 clients totaling 6 players in total can be in a world. That's 5 Duelist or 3 Invaders and 2 White Phantoms.
-  Bonfire resting possible for all players during a session, excluding invaders.
- Rune arc always active.
- Custom Arena respawns. Inside 2v2 and 3v3 arena's player cannot dies and instead get respawned similar to Colosseum respawn. 
- Custom items. ERC hosts a number of custom items. See #🗒️-resources for information on them.
- Match countdowns. By interacting with any of the start match emblems/swords (or F2) you can display a match count down timer for all players.
- Team fights in Colosseum matches shows players as Blue or Red for better distinction 
- Custom PvP maps. ERC many a number of PvP focused custom maps. The list of maps is ever expanding and we look forward to introducing new experiences for all players.
- Our own "Covenant" system called the Symbol system. ERC recovers the cancelled Covenant content and introduces a reward system that allows players to equip Symbol items in their Covenant slot. These Symbols allow players to display custom phantom colors, animations, and vfx. This system is still in development but you can equip the two test items to try out the custom phantom properties.
- Faster bonfire resting animations with vfx similar to previous souls games
- The Black Market. A shop to purchase all items available in the game including Max'd weapons and Combatants items
- LevelUp , Rebirth, and  Strengthen Weapons options are all available and free at the bonfire
- Transmog. ERC introduces ThomasClark's [transmog system](https://www.nexusmods.com/eldenring/mods/3596).
- Imported Armor Sets for transmog. ERC not only has transmog but also has armors from previous titles. (Right now DS3 only and more to come)
- Blood Message Removal. In ERC all messaging is disabled. This is a proactive approach to cut down on player griefing via the blood message system.
- Player Freezing. ERC allows host who are doing tournaments or fc's to freeze all participating players in arenas by pressing F3. Useful for moments where a player may have broken a rule
- Open Camera using item  Invigilator Monitor or pressing F5. This allows hosts to observe player gameplay through a custom camera mode. Press X/A to view controls while activated
- Class Changing and Stat Reset at bonfire
- Updated Player Name Tags: Players now show Ping, Country, Packetloss, and Rune Level above their heads. This is all configurable in cmbt-config.ini. Including a anonymous mode for player names.
- Automatic Summon Sign activating without having to interactive with summon signs directly
- New Player QOL features. When starting new games you will have all basic features, whetstones, cookbooks, maps, graces, colosseums, perfumes, pots, and memory slots unlocked. Resting at the bonfire as a new player will award you all multiplayer items, flasks, and horses.
- Character Build Importer. ERC introduces a build importer that allows players to import builds made through [Emelia's Build Planner](https://er-build-planner.nyasu.business/)
- Give all items option at the bonfire. This feature allows players to get all items of the chosen item type. Similar to Gigagib
